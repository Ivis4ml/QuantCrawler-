概览

一个可断点续跑的学术采集器

纯 Python 命令行工具。元数据来自免费学术 API（OpenAlex / Crossref / Unpaywall / arXiv），状态记在 SQLite，每个阶段幂等、可续跑。仅下载合法开放副本，付费墙论文只记元数据。

采集范围

20+ 顶刊 · 四个主题

核心金融三大刊、微观结构 / 量化 / 数理金融、计量 / 统计 / 管理科学（仅金融相关）。主题聚焦二级市场、微观结构、高频、量化因子，排除公司金融 / 银行 / 宏观。

规模

4,590 篇相关论文

2020–2026 窗口内，按类别分口径筛出的相关论文。完整清单见 paper_list.csv，未下载的进 download_worklist.csv。

特性

工程要点

数据源

四个免费 API

OpenAlex 元数据 / OA / 主题，Crossref 兜底，Unpaywall 定位 OA，arXiv 匹配预印本。全部 polite pool。

相关性筛选

按期刊类别分口径

金融本位刊宽口径；非金融刊只认金融关键词，避免误收通用统计 / ML 论文。

并发与健壮

线程池 + 流式

按主机限速（arXiv 单独 1rps），流式落盘、校验 %PDF、sha256、原子写入、断点续传。

幂等存储

SQLite 状态机

每篇记 download_status、pdf_source、sha256。重跑只处理未完成项；列以单一来源驱动建表与自动迁移。

可交接

两机无缝衔接

私下传 data/ 即可续跑，下过的自动跳过；reconcile 命令按确定性路径对齐磁盘上的 PDF。

快速开始

三步跑起来

# 1) 安装（仅 httpx + pyyaml）
pip install -r requirements.txt

# 2) 一条命令跑全流程
python -m quantcrawler run

# 3) 看进度
python -m quantcrawler stats
→ downloaded: 926   paywalled: 2966   failed: 698   pending: 0

关于合规

本项目仅下载合法开放获取副本，不绕过付费墙。下载的 PDF 不进公开仓库（版权：可免费阅读 ≠ 可公开再分发），通过私下渠道交接。公开仓库只含代码与书目元数据。
