欢迎接手 QuantCrawler

你将接手一个已经在运行的金融论文采集器。系统已经把能免费拿到的论文下好了，你的任务是用学校校园网，把还在付费墙后面的论文合法地下载下来，并回填到系统里。不需要很强的基础，跟着这份指南一步步做即可。本指南面向 Windows。

这个项目是什么

QuantCrawler 是一个爬虫，从 21 本金融与量化顶刊里，找出 2020–2026 年发表、和二级市场、市场微观结构、高频交易、量化因子相关的论文，记录信息并下载原文 PDF。

它只下载合法的开放获取（免费可下）版本。大量顶刊论文在出版社付费墙后面，脚本下不到，这部分需要用学校的订阅（校园网）在浏览器里下载。这就是交给你的活儿。

i
你会学到：Git、Python 基础、命令行、用 AI 辅助写代码（vibe coding）、以及用 Codex 的 computer use 借校园网把付费墙文献批量下载下来。边做边学，不懂就问 Codex 和看文档。

仓库里都有什么

拿到代码后，你主要打交道的是带 ★ 的几个。代码本身（quantcrawler\）一般不用改。

config\journals.yaml21 本期刊清单
config\settings.yaml设置：主题词、限速、时间窗口
★ data\pdfs\下载的 PDF，按 期刊\年份\ 存放

★ data\reports\download_worklist.csv你的工作清单：还没下到的论文 + DOI + 链接

03

环境准备（Windows，一步步来）

全程在 PowerShell 里敲命令。开始菜单搜「PowerShell」，右键「以管理员身份运行」打开。下面每个代码块右上角都能点「复制」。

装 Python 3.11 或更高

去 python.org 下载安装。安装第一屏务必勾上「Add python.exe to PATH」，否则命令行找不到 python。装完在 PowerShell 验证：

Windows PowerShell
python --version
# 看到 Python 3.11.x 或更高就对了。若提示找不到，试 py --version

装 Git

去 git-scm.com 下载 Git for Windows，一路默认安装。验证：

Windows PowerShell
git --version

下载（克隆）代码

选个你放代码的文件夹（比如桌面），克隆仓库并进入：

Windows PowerShell
cd $HOME\Desktop
git clone https://github.com/Ivis4ml/QuantCrawler-.git
cd QuantCrawler-

装依赖

只有两个依赖，很快：

Windows PowerShell
pip install -r requirements.txt

放入导师给你的数据包

导师会私下给你一个 quantcrawler-data.tgz（里面是已经下好的 496 篇 PDF + 进度数据库）。把它放到项目根目录 QuantCrawler-\ 里，然后解包（Win10/11 自带 tar）：

Windows PowerShell
tar -xzf quantcrawler-data.tgz
# 解出 data\pdfs\ 和 data\catalog.sqlite。若 tar 不可用，用 7-Zip 解压两次。

验证：能看到已下载的数

跑一下统计，看到 downloaded 大约 496 就说明环境和数据都对了：

Windows PowerShell
python -m quantcrawler stats
→ downloaded: 497   paywalled: 3360   failed: 733   pending: 0
!
如果 python 找不到：用 py 代替（如 py -m quantcrawler stats），或重装 Python 时记得勾「Add to PATH」，再重开 PowerShell。
04

你的任务 ★

你的任务有两块。主线：用 Codex 的 computer use 借校园网 VPN，把付费墙后的约 4,093 篇文献拿下来。副线：在本地接着现有进度，把还能免费爬的开放获取继续爬完。

每一篇下不到的论文都在清单 data\reports\download_worklist.csv 里，每行带 DOI 和 出版社落地页链接。这就是主线的输入。

主线 ★：用 Codex computer use + 校园网拿付费墙文献

思路：先连校园网（让浏览器有出版社订阅权限），再让 Codex 的 computer use 在这个已登录的浏览器里，按清单一篇篇「打开落地页 → 点下载 PDF → 保存 → 用 import-pdf 归位」。你在旁边盯着、控制节奏。这是这份工作最重要的部分。

连上校园网 / 学校 VPN

用学校 VPN 或 EZProxy 登录。这一步给你出版社的订阅访问权，合法的正常使用。先手动确认：在浏览器里能打开一篇付费墙论文并看到真正的 PDF。

打开 Codex，指向这个项目

在项目目录里启动 Codex（它会自动读 AGENTS.md 了解项目）。确保它的 computer use / 浏览器 能力可用，并且用的是你已登录校园网的浏览器会话。

把任务交给它（示例提示）

让它读清单、逐条用浏览器下载、再回填。可以这样对 Codex 说：

给 Codex 的提示
读 data\reports\download_worklist.csv 的前 20 行。
对每一行，用 computer use 在浏览器里打开它的 pdf_landing
（或 https://doi.org/ 加上 doi），下载该论文的 PDF 到 Downloads，
然后运行：
  python -m quantcrawler import-pdf --doi 这行的doi --file 下载到的路径
每篇之间停几秒；遇到打不开或没有 PDF 就跳过并记录下来。

盯着它跑，分批放大

先跑一小批（如 20 篇）确认它点得对、归位成功，再逐步放大。import-pdf 会校验是不是真 PDF，并自动归位到 data\pdfs\期刊\年份\ + 标记完成，下次清单里就没它了。每天约 200 篇，两周覆盖大部分。

!
红线：低频、人工盯着、守出版社条款。 用机构账号高频批量自动抓取，可能导致整个学校的访问被封。这是「让 Codex 帮你点浏览器」，不是绕过付费墙。宁可慢，别莽；批量之间留足间隔。

手动兜底：一篇一篇自己来

Codex 用不了、或某篇它搞不定时，自己在校园网浏览器里把 PDF 下好（下到 Downloads），再用同一条命令归位，不用管放哪、叫什么名：

Windows PowerShell
python -m quantcrawler import-pdf --doi 10.1093/rof/rfaa027 --file $HOME\Downloads\paper.pdf
→ 已归位并标记 downloaded

副线：本地继续爬免费 OA

免费 OA 这部分已经跑完了（共 497 篇）。下面几条命令留着备用：以后想再确认有没有新放出的免费版本，可以再跑一遍（已下过的不会重下）：

Windows PowerShell
python -m quantcrawler resolve-pdfs   # 定位还能免费拿到的（偏慢，arXiv 限速）
python -m quantcrawler download       # 把新定位到的下下来
python -m quantcrawler report         # 刷新清单与统计

这步偏慢，可以让它在后台跑着；命中的自动进 data\pdfs\，没有免费副本的会留在付费墙清单里，交给主线（Codex + 校园网）。

06

用 Codex 帮你（vibe coding）

本项目用 Codex（OpenAI 的 AI 编码助手）来做。它能读代码、跑命令、改文件，还能用 computer use 点浏览器，上面的主线就靠它。下面是怎么把它用起来。

装好并在项目里打开

Codex CLI 需要 Node.js。先去 nodejs.org 装好 Node，然后在 PowerShell 里：

Windows PowerShell
npm install -g @openai/codex
cd $HOME\Desktop\QuantCrawler-
codex
# 首次启动会让你用 ChatGPT 账号登录

在项目目录里启动后，Codex 会自动读 AGENTS.md，立刻明白这个项目是什么、有哪些命令、有哪些规矩。之后你直接用中文给它派活就行。

这样用它

  • 看不懂代码 / 命令？ 直接问，例如「解释一下 import-pdf 这个命令做了什么」。
  • 报错了？ 把整段报错贴给它，让它告诉你怎么修。
  • 主线（最重要）： 让它用 computer use 按 download_worklist.csv 在校园网浏览器里下载付费墙论文、再调 import-pdf 归位（提示词见第 04 节）。
  • 不确定合不合规？ 先问它、先小批量试，再放大。

用得稳的几个习惯

  • 从保守模式起步： 让 Codex 在跑命令 / 点浏览器前先征求你同意，确认没问题，再逐步提高它的自主度。
  • 小步快跑： 一次只让它改一点、下一小批，每次都跑一下看对不对，别一口气放它跑几百篇。
  • 先看文档： 遇到不懂，先翻 AGENTS.md、CLAUDE.md 和这份指南，再问它。
i
心法：小步快跑 + 人工在环。Codex 很强，但你要盯着它：小批量验证对了再放大，付费墙下载尤其要控速、守条款。
07

常见问题

import-pdf 说「库中未找到该论文」？

确认你用的 DOI 确实在 paper_list.csv 里。本项目只收录 21 刊、2020–2026、四个主题的论文；不在范围内的不会被收录，也不用下。

下下来打开是网页、不是 PDF？

说明没真正拿到原文（多半是没登录校园网，或那篇本身就付费墙）。检查 VPN 是否连上、是否在出版社页面看到了真正的 PDF 按钮。import-pdf 也会校验文件开头是不是 %PDF，不是会拒绝。

python 命令找不到？

用 py 代替，或重装 Python 勾「Add to PATH」后重开 PowerShell。

路径里有空格 / 中文？

给路径加引号，例如 --file "C:\Users\我 的\Downloads\a.pdf"。

!
三条红线：(1) PDF 不传公开仓库；(2) 不要用脚本高频猛刷出版社，会封整校；(3) 只下你学校有权限的，不破解付费墙。

Windows PowerShell
python -m quantcrawler reconcile
