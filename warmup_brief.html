05 · 瓶颈

那堵 403 的墙

顶刊原文 PDF 直链几乎都在出版社站点，用 Cloudflare 反爬：对没有浏览器会话、没有机构订阅的脚本请求，直接返回 403。

瓶颈 1 · 主因

出版社 403 / Cloudflare

Wiley pdfdirect、OUP、Elsevier 对脚本返回 403。这不是 bug，是反爬；只有带认证的真实浏览器能过。

瓶颈 2 · 速度

arXiv 解析慢且低产

每篇 closed 论文都要按标题查一次 arXiv，限速 1rps，约 4.5 秒/篇，命中率仅约 6%。

瓶颈 3 · 摘要缺失

Elsevier 限制摘要

JFE 等摘要重建率仅约 18%，筛选更依赖标题与主题标注。

不是瓶颈

采集与并发已解决

元数据完整、下载已并发流式化。剩下的纯粹是访问权问题，这就是你的真题。

06 · 你的任务

把那 ~3,600 篇拿下来

输入是 download_worklist.csv（DOI + 出版社落地页 + 期刊 + 年份）。用两条合法路径，把原文补进 data/pdfs/。

推荐先做

校园网 / 机构订阅

  • 用学校 VPN 或 EZProxy 登录，获得出版社订阅访问权
  • 在已认证的浏览器会话里，按 worklist 的 DOI 打开落地页下载 PDF
  • 合法：你的机构有订阅，这是正常使用
  • 节奏：约 200 篇/天，两周覆盖大部分
注意：机构访问受出版社条款约束，批量自动抓取可能导致整校访问被封。务必低频、人工在环。
主线 · 最重要

Codex computer use + 校园网

  • 先连校园网 / VPN，让浏览器有出版社订阅权限
  • 用 Codex 的 computer use 驱动这个已登录的浏览器
  • 读 worklist → 逐条打开落地页 → 下 PDF → import-pdf --doi … --file … 自动归位
  • 先跑一小批确认，再分批放大；人工盯着
务必低频、人工监督、守出版社条款。机构账号高频批量抓取可能导致整校访问被封。这是「让 Codex 替你点浏览器」，不是绕过付费墙。

07 · 交接与合规

PDF 不上传，但你能无缝接手

下载的 PDF 不进公开仓库（版权：可免费阅读 ≠ 可公开再分发）。代码与元数据公开，PDF 私下传给你，且下过的不用重下。

为什么不公开 PDF

「可读」≠「可再分发」

已下载的许可类型混杂（green / hybrid / bronze），bronze 等只授权阅读、不授权转发。公开上传有版权与 DMCA 风险，故 PDF 与数据库已 gitignore。

公开仓库放什么

代码 + 元数据，不含 PDF

代码、配置、文档，加 paper_list.csv、download_worklist.csv、summary.md。书目元数据（DOI / 标题 / 链接）来自 OpenAlex（CC0），可公开。

无缝衔接 · 原理

下过的自动跳过

每篇有 download_status；download 只挑 pending；即便选中，文件已存在也直接跳过、不发请求。双保险。

兜底 · reconcile

只拿到 PDF 也能对齐

没拿到数据库时，harvest 重建后跑 reconcile，按 (期刊, 年, DOI) 路径扫磁盘，把已有 PDF 标记 downloaded。
